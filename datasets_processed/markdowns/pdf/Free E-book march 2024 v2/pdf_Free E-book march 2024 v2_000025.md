<|en|><|problem|>Let’s open a Timeline so we can animate the Camera. Select the Camera and add a keyframe at frame 1 by pressing i and choosing Location & Rotation or Location & Rotation & Scale. Right-click on the keyframe and set the key to Linear interpolation so the movement is linear instead of easing in. I’ll change the resolution to a more standard 4K format. When using fSpy, it will set the scene to a strange resolution. 4K is 3840 x 2160 pixels (1920 x 1080 multiplied by 2). And then we can go to a later frame (frame 120 for example) and move the Camera to a new position by pressing G. By holding Shift, it’s easier to make a subtle change in the location of the Camera. I recommend doing this in the T op Orthographic view. You can’t go too crazy with the camera position before you start seeing weird stretched parts of the texture, so it’s best to keep the camera move subtle. Set another keyframe.<|final|>
