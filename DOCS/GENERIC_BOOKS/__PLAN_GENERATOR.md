# Plan de Generacion: 150 Libros Tematicos en Espanol

## Objetivo

Generar **150 archivos Markdown individuales**, cada uno un libro completo de **150-300 KB** sobre un tema especifico. Un topic = un MD = un libro.

## Restricciones

- **NO** se utilizan archivos AIML ni tecnicas similares de generacion automatizada
- Todo el contenido es **escrito directamente** con parrafos elaborados
- Idioma: **Espanol peninsular** (castellano)
- Nivel: **Divulgativo / basico** para ciencias, **general** para el resto
- Temas **apoliticos y correctos**: sin contenido polemico, ideologico ni sensible
- Formato: **libro en MD** con capitulos, secciones y subsecciones

## Estructura del Proyecto

```
GENERIC_BOOKS/
├── __PLAN_GENERATOR.md          <- Este archivo
├── topics.json                  <- Indice de 150 topics individuales
├── 001_historia_union_europea.md
├── 002_parlamento_europeo.md
├── ...
├── 040_futuro_union_europea.md
├── 041_saludos_presentaciones.md
├── ...
└── 150_educacion_formacion.md
```

## Formato de Cada Libro

Cada MD sigue la estructura de un libro:

```markdown
# [Titulo del Libro]

## Capitulo 1: [Nombre del Capitulo]

### [Seccion 1.1]
Parrafo elaborado de 4-6 oraciones con informacion detallada,
ejemplos, contexto historico y aplicaciones practicas.

### [Seccion 1.2]
Otro parrafo complementario con mas detalles y profundidad.

## Capitulo 2: [Nombre del Capitulo]
...
```

## Pipeline de Integracion

Una vez generados los MDs, se integran al entrenamiento con:

```bash
# Copiar MDs a datasets_source/markdown/
cp GENERIC_BOOKS/*.md datasets_source/markdown/

# Preparar datos
python main.py --prepare-data --markdown --aiml

# Entrenar
python main.py --train --epochs 30
```
