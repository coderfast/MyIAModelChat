# Plan de Generacion: 150 Libros Tematicos en Espanol

## Objetivo

Generar **150 archivos Markdown individuales**, cada uno un libro completo de **150-300 KB** sobre un tema especifico. Un topic = un MD = un libro.

## Restricciones

- **NO** se utilizan archivos AIML ni tecnicas similares de generacion automatizada
- Todo el contenido es **escrito directamente** con parrafos elaborados
- Idioma: **Espanol peninsular** (castellano)
- Nivel: **Divulgativo / basico** para ciencias, **general** para el resto
- Temas **apoliticos y correctos**: sin contenido polemico, ideologico ni sensible
- Formato: **libro en MD** con capitulos, secciones y subsecciones

## Estructura del Proyecto

```
GENERIC_BOOKS/
├── __PLAN_GENERATOR.md          <- Este archivo
├── topics.json                  <- Indice de 150 topics individuales
├── 001_historia_union_europea.md

├── ...
```
