The von Neumann architecture is the fundamental model that describes how modern computers work. The history of computers begins long before electronics. The abacus, invented in Mesopotamia over 4,000 years ago, is the first known calculation tool. A computer's memory is organized in a hierarchy that balances speed, capacity, and cost. CPU registers are the fastest but smallest, capable of storing only a few bytes of data. CPU cache is very fast memory that stores data and instructions the processor uses frequently, with multiple levels (L1, L2, L3) that vary in size and speed. Permanent storage includes hard drives (HDD) and solid-state drives (SSD). HDDs use spinning magnetic disks to store data, with capacities that can exceed 20 terabytes but with relatively slow read/write speeds. SSDs use flash memory, with no moving parts, with read/write speeds much faster than HDDs but at a higher cost per gigabyte. Virtual memory is a technique that uses permanent storage as an extension of RAM. When RAM fills up, the operating system temporarily moves data from RAM to the hard drive, creating a swap space. Virtual memory allows computers to run programs that require more memory than is physically available, but at a performance cost, since hard drive access is much slower than RAM access. Optimizing the memory hierarchy is a constant challenge in computer design, as the speed gap between the CPU and storage is one of the most significant bottlenecks in system performance.

Modern operating systems use multitasking to run multiple processes simultaneously. Multitasking allows the CPU to rapidly switch between different processes, creating the illusion that they are running at the same time. Operating systems can be cooperative multitasking, where processes voluntarily yield CPU control, or preemptive multitasking, where the OS assigns execution time slices to each process and switches between them automatically. Preemptive multitasking is the standard in modern computers, as it provides better performance and prevents a process from monopolizing the CPU.
