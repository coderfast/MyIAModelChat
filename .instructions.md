# MyIAModelChat Project Instructions

## Project Overview
MyIAModelChat is an advanced AI chat model that combines multiple NLP techniques:
- **Neural Architecture**: LSTM-based PyTorch model with embedding and fully connected layers
- **Intent Recognition**: BERT-based intent classifier to detect user intent
- **Sentiment Analysis**: BERT-based sentiment analyzer for emotional context
- **Dialogue Management**: Context-aware dialogue manager with conversation history
- **AIML Integration**: AIML (Artificial Intelligence Markup Language) pattern matching
- **Custom Tokenization**: Simple custom tokenizer for text processing

## Key Components

### Core Python Modules
- **chatmodel.py**: PyTorch neural network model (Embedding → LSTM → FC layer)
- **dialogmanager.py**: Manages dialogue flow, intent recognition, sentiment analysis, and persona modeling
- **chatdataset.py**: PyTorch Dataset class for loading chat data
- **simpletokenizer.py**: Custom tokenizer for encoding/decoding text
- **aimlloder.py**: Loads and manages AIML files for pattern matching
- **main_train.py**: Training pipeline with dataset handling
- **main_chat.py**: Chat interface for inference
- **main.py**: Primary entry point

### Data & Models
- **aiml/**: AIML files (~60 files) for dialogue patterns
- **aiml_dev/**: Development AIML files with datasets
- **datasets/**: Training data directory
- **.pth files**: Saved model weights (`chat_model.pth`)

## Development Workflow

### Training
```bash
python main_train.py --epochs 10 --num-cores 4 --aiml --hf
```
Key options:
- `--epochs`: Number of training epochs
- `--num-cores`: CPU cores for data loading
- `--aiml`: Include AIML data
- `--hf`: Include Hugging Face datasets

### Inference/Chat
```bash
python main_chat.py
```

### Environment
- Python 3.12 compatible
- Virtual environment: `envMyIAModelChat/`
- Key dependencies: torch, transformers, python-aiml, datasets

## Architecture Notes

### ChatModel Flow
1. Input tokens → Embedding layer (vocab_size → embedding_dim)
2. Embeddings → LSTM layer (processes sequences, outputs hidden states)
3. LSTM output → Fully connected layer (hidden_dim → vocab_size)
4. Output → Logits for next token prediction

### DialogueManager Flow
1. User input received
2. Intent classification (BERT)
3. Sentiment analysis (BERT)
4. Context maintained in deque (max_history=5 turns)
5. Persona-based response generation
6. Model inference
7. Response decoded and returned

## Common Tasks

### Adding New AIML Patterns
- Add .aiml files to `aiml/` directory
- Use standard AIML XML structure
- Update main_train.py to include new files

### Modifying Model Architecture
- Edit `chatmodel.py` ChatModel class
- Retrain with new parameters
- Update saved weights

### Extending Dialogue Context
- Modify `max_history` parameter in DialogueManager
- Adjust context window for longer conversations

### Fine-tuning Intent/Sentiment
- Replace transformers pipeline models
- Retrain on domain-specific data
